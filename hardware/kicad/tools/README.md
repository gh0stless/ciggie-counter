# Generators for the Butt Bin board

Schematic and board in `../buttbin_carrier/` are generated by these scripts (KiCad 10).
Edit the scripts, not the generated files, then regenerate:

```sh
# 1. schematic (plain Python 3): writes buttbin_carrier.kicad_sch, ButtBin.kicad_sym, sym-lib-table
python gen_sch.py ../buttbin_carrier

# 2. netlist for the board
kicad-cli sch export netlist --format kicadsexpr -o bb.net ../buttbin_carrier/buttbin_carrier.kicad_sch

# 3. board (KiCad's own Python, it needs the pcbnew module): placement, routing, GND pour
"<KiCad>/bin/python" gen_pcb.py bb.net ../buttbin_carrier/buttbin_carrier.kicad_pcb

# 4. checks
kicad-cli sch erc ../buttbin_carrier/buttbin_carrier.kicad_sch
kicad-cli pcb drc ../buttbin_carrier/buttbin_carrier.kicad_pcb

# 5. JLCPCB data (plain Python 3): gerber zip, BOM and CPL in ../buttbin_carrier/fertigung/
python gen_fab.py ../buttbin_carrier
```

The CPL takes KiCad's rotations as they are; check them in JLCPCB's placement preview
(LEDs and the module are the usual suspects). Test pads (TP*) are copper only and are left
out of BOM and CPL.

The KiCad libraries are found automatically in the usual install locations; otherwise set
`KICAD_SHARE` to the folder that contains `symbols/` and `footprints/`.

`gen_pcb.py` has a small grid router of its own (two layers, vias, 0.2 mm tracks, 0.15 mm
clearance). It is good enough for this simple board; check the DRC and look at the result.
